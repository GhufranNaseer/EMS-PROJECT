SECTION 7: DEPLOYMENT PROCESS STEP BY STEP
============================

Step 1: Infrastructure Check
  - CPU check       : top -bn1 | head -5
  - RAM check       : free -h
  - Disk check      : df -h
  - Docker health   : docker info
  - Port conflicts  : ss -tulpn

Step 2: Analyze New Project Files
  - Read docker-compose.yml
  - Read Dockerfile
  - Find all ENV variables needed
  - Note existing port assignments in compose file

Step 3: Prepare Environment
  - Create .env file with correct values
  - Modify docker-compose.yml for new project:
      * Change container names (unique prefix)
      * Change port mappings (avoid conflicts)
      * Change network name (unique)
      * Change volume names (unique)
      * Add project name

Step 4: Database Setup
  - Start MySQL container first
  - Wait for MySQL to be ready
  - Import exhibition_system.sql
  - Verify database import

Step 5: Build & Start
  - cd /var/www/exhibition_system_prod
  - docker compose -p ems_prod up -d --build
  - Watch build logs

Step 6: Verify Health
  - docker ps (check all containers running)
  - docker logs [container_name] (check for errors)
  - curl http://localhost:[new_port] (check HTTP response)

Step 7: Configure Nginx
  - Create NEW file: /etc/nginx/sites-available/ems_prod
  - DO NOT modify: /etc/nginx/sites-available/exhibit.com.pk
  - Test config: sudo nginx -t
  - Reload: sudo nginx -s reload (DO NOT restart)

Step 8: SSL (if domain provided)
  - sudo certbot --nginx -d [new_domain]

Step 9: Final Verification
  - All containers healthy: docker ps
  - Application responding: curl
  - Database connected: check app logs
  - Existing production still working: curl https://exhibit.com.pk
